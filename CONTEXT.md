# GReader

GReader is an instructor-facing workspace for preparing programming assignments and their evaluation examples.

## Language

**Instructor**:
The person who creates and maintains programming assignments.
_Avoid_: Teacher, admin, user

**Assignment**:
A programming problem prepared by an Instructor, including its statement, constraints, and owned Test Cases.
_Avoid_: Challenge, task, question

**Test Case**:
One input and expected output pair owned by an Assignment. It cannot exist independently.
_Avoid_: Example, check

**Topic**:
A reusable subject classification that an Assignment may reference, such as arrays, graphs, or dynamic programming.
_Avoid_: Tag, category, label
