## Decisions made after ADR-0007 (not in the ADR)

- **503 until OPS-15**: production wires `database/pending.py` (`PendingRepository`), which refuses every call; main.py maps `SliceNotPersistedError` to 503. Routers stay mounted.
- **Role rule** is "never *branch* on a role" in routes/pages; serializing one is fine. AGENTS.md wording and the architecture test changed on the feature branch.
- **Domain-field allowlists** in `tests/architecture/test_conventions.py` gained `user_id`, `instructor_id`, `classroom_id`, `student_id`, `expires_at`, `last_active_at`, `requested_at`, `joined_at`, each with the use case that reads it.
- **Verification mail** goes through a temporary auth port `VerificationMailer` (stub in `integrations/email.py`). When notifications lands, main.py points it at `NotificationService`; nothing else changes.
- **Tabs**: a Member asking for an Instructor tab gets 403; an unknown tab gets 404.
- **Demo mode** lives in `scripts/demo.py`, not a `GREADER_DEMO` switch in main.py, because fakes may not ship in `src/`. Demo card numbers are hard-coded from the prototype until assignments/submissions compute them.
- **Templates**: page templates use only the `_components/` macros for controls (architecture test). Server-rendered open modals (C-02a, C-03a) use `modal(static=true)`.
- **CSS**: Tailwind v4.3.3 standalone binary, not in the repo; README "Styles" has build/watch commands. Root font size stays 16px, body text 13px.
- Classroom summary/CSV endpoints were moved to the submissions slice, where their data lives.
