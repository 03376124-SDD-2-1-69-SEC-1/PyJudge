How it works

  1. Step 1

    Create a classroom and share the code

    Each section gets a six-character join code. Students enter it to join.

  2. Step 2

    Generate a problem from your PDFs

    The draft cites the pages it came from. Review it, edit it, then publish.

  3. Step 3

    Students submit and are graded

    Every submission runs against the sample and hidden tests. The score shows right away.

For instructors

  • Keep your lecture PDFs in one library.
  • Draft problems with tests, each citing its source pages.
  • Publish one problem to several classrooms, each with its own deadline.
  • See who passed, who is late and which test fails most.

For students

  • Join a classroom with the code your instructor shares.
  • Run your code on the sample tests before you submit.
  • See your score and which tests passed as soon as you submit.
  • Get told when a problem changes and you need to resubmit.
